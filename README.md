# Neptun Alerts & Galaxy Watch Complication

Мультимодульний проєкт для Android та смарт-годинників Samsung Galaxy Watch (Wear OS 3.0+), який відстежує повітряні тривоги в Україні у реальному часі через відкритий API [neptun.in.ua](https://neptun.in.ua/developers).

## Структура проєкту

- **`:mobile`** — Android додаток для смартфона:
  - Фоновий сервіс (`ForegroundService`) з постійним WebSocket з'єднанням (`wss://neptun.in.ua/api/v1/stream`) та REST fallback (`GET /api/v1/alerts`).
  - Вибір регіону: багаторівневий (Область -> Район або «Вся область»).
  - Налаштування звуку та вібрації при тривозі / відбої.
  - Автоматична передача статусу на годинник через Google Play Services Wearable Data Layer API.
- **`:wear`** — Додаток для Samsung Galaxy Watch (Wear OS):
  - **Complication Provider** (`AlertComplicationService`), що підтримує слоти `SHORT_TEXT` та `LONG_TEXT` на будь-якому циферблаті.
  - Індикація тривоги (?? «ТРВ» / час), спокою (?? «ОК») та втрати зв'язку з телефоном (?? «—» при відсутності оновлень > 15 хв).
  - Екран деталей (`AlertDetailScreen`) при натисканні на Complication з інформацією про тривалість, район та кнопкою ручної синхронізації.
  - Фоновий слухач `WearDataListenerService`, що миттєво оновлює циферблат при зміні даних на смартфоні.
- **`:shared`** — Спільна бібліотека:
  - Моделі даних `AlertStatus`, `Region`, `District`, DTO відповідей Neptun.
  - Вбудований повний довідник усіх 25 областей та районів України за новим адміністративним поділом.
  - Константи шляхів Wearable DataLayer (`/alert_status`, `/request_sync`).

## Як відкрити та запустити

1. Відкрийте папку `d:/src/alerts` в **Android Studio**.
2. Дочекайтеся завершення Gradle Sync.
3. **Запуск мобільного додатку**:
   - Оберіть конфігурацію `:mobile` та запустіть на фізичному смартфоні або Android-емуляторі.
   - Оберіть область/район та надайте дозвіл на сповіщення.
4. **Запуск додатку для годинника**:
   - Оберіть конфігурацію `:wear` та запустіть на Galaxy Watch (через Wireless Debugging) або Wear OS емуляторі.
5. **Додавання Complication на циферблат**:
   - На годиннику затисніть поточний циферблат -> «Налаштувати» (Customize).
   - Оберіть слот ускладнення (Complication) -> у списку джерел оберіть «Тривоги» -> «Статус повітряної тривоги».
